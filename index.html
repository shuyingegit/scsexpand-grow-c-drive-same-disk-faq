Grow Windows C: from free space on the same disk

Short answer: move unused free space on the same physical disk into the C: volume so Windows stops running out of system disk space.

ScsExpand does this on Windows. It is not a WebDAV/NAS mount (ScsDrive) and not a folder→drive-letter map (ScsSubst).

Does it reformat, or does it merge partitions?

Neither. Free space is taken from another partition on the same physical disk and given to C:. No reformat, no partition merge, files stay in place — the capacity simply moves from one partition to another. It is not a reinstall and not a data-losing merge.

What does it refuse to do?

The pre-check rejects what it cannot handle before anything is started, with the reason given, instead of starting an operation that ends in a format prompt:

  • free space sitting on a second physical disk — that is a different operation;
  • a BitLocker-locked volume;
  • a non-NTFS source partition (FAT32, for instance);
  • dynamic disks.

Does it need a reboot, and is it a WinPE session?

One restart is needed, and it is not a WinPE session. The heavy part runs in a guided restart environment: ScsExpand prepares a small boot agent, registers a one-time boot entry, the machine restarts, the resize is applied, and Windows comes back on its own.

Before you start

  • Take a backup. Resizing a system partition is the one operation here that can cost you data if something goes wrong.
  • Check what is actually "unallocated": three different things get called that in a partition table, and they are not interchangeable.
  • Suspend BitLocker yourself if you use it, and remember to turn it back on afterwards.
