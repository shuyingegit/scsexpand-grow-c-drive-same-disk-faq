# FAQ：用同一块盘上的空闲空间给 Windows C 盘扩容

预算里没有新硬盘的时候，能把同一块物理盘上闲置的空间给 C 盘，这是常被问到的问题。先做利益披露：ScsExpand 是我们做的（https://expand.scsoi.com/），所以提到产品的地方请当成有倾向；下面的 Windows 行为本身不是我们的说法。

## 它会格式化、或者合并分区吗？

都不会。空闲空间从同一块物理盘上的另一个分区划给 C:，**不格式化、不合并分区、文件留在原地**，容量此消彼长。不复制、不删除任何东西。

## 哪些情况它做不了？

前置检查会在**动手之前**就拒绝，并把原因讲清楚，而不是做到一半弹出「要格式化吗」：

- 空闲空间在**第二块物理盘**上（那是另一回事）；
- **BitLocker** 锁定的卷；
- 源分区**不是 NTFS**（比如 FAT32）；
- **动态磁盘**。

## 重启是进 WinPE 吗？

不是。需要重启一次，重活跑在**引导式重启环境**里：程序准备一个小的启动代理、注册一次性启动项，机器重启、扩容执行完，Windows 自己回来。

## 多少钱？

无广告。免费下载本身就是试用：可扩容 1 次、单次最大 5 GB，额度按次数和大小算，不是按试用天数。**一次买断**之后扩容次数与大小不限（只受该盘空闲空间限制），**不强制订阅**。

## 动手之前我要检查什么？

- **先做备份**。这一类操作里，改系统分区是唯一可能以数据为代价的。
- 搞清楚你手上那个「未分配空间」属于哪一种。分区表里有三种东西被叫作未分配空间，彼此不能互换。
- 如果你用 BitLocker，先自己挂起，操作完记得再打开。
